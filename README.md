# AIS Workshop: Linear Regression  

This repository contains the **Linear Regression Workshop Notebook** used to practice intermediate Git commands.  

### 📘 Overview
- Covers concepts like cost function (MSE), gradient descent, train/validation/test splits, and model evaluation (MAE, RMSE, R²).  
- Uses the **California Housing dataset** to demonstrate supervised learning.  
- Implemented with **NumPy, Pandas, Matplotlib**, and **Scikit-learn**.  

### ⚙️ Git Commands Practiced
- Initialized local repository with `git init`
- Staged and committed notebook using `git add` and `git commit`
- Linked to GitHub remote and pushed with `git push -u origin main`
- Created and edited README file to document the project

### 🧠 Purpose
This repository was created as part of an **AI Society workshop** to demonstrate both **machine learning implementation** and **intermediate Git proficiency**.
